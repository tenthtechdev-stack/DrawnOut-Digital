# Portfolio motion exports

The current review has three upgraded pilots and three preserved legacy projects. All remain subject to the website's publication and withdrawal controls; source exports live outside public/.

## First-three creative review

Bunzo, SOL Community Center and Churros use independently isolated source-art layers. Each silent H.264 High/yuv420p loop runs 7.5 seconds at 24 fps (180 frames), CRF 19 with faststart and explicitly declared limited-range BT.709 conversion, primaries, transfer and matrix metadata. Actual browser pixels are compared with original source/poster pixels.

| SOL Community Center | 1440 × 810, 943,778 bytes | 810 × 1080, 792,030 bytes |
| Churros              | 1440 × 810, 668,984 bytes | 810 × 1080, 667,759 bytes |

Rebuild the first three with:

```sh
node scripts/portfolio/quality/render.mjs
node scripts/portfolio/quality/verify-browser-color.mjs
node scripts/portfolio/quality/create-previews.mjs
node scripts/portfolio/promote-quality.mjs
node --test tests/portfolio-motion-exports.test.mjs tests/motion-quality-exports.test.mjs
```

The SVG still snapshots generated by the renderer embed duplicate image data and remain local ignored outputs. The JavaScript compositions, source-pixel masks, individual layer PNGs and manifests are the committed reproducible sources.
