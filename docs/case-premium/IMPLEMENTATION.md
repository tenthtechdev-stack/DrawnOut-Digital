## Scope and content

The remaining six routes continue using the original case-study component pending owner approval of these pilots. Current project records, publication selectors, service routes, site navigation and Work ordering are canonical and unchanged.

A server-side presentation adapter resolves each selected image from that approved record's cover/gallery. No image is imported independently to bypass publication withdrawal. Only five approved slugs opt in; a missing asset or withdrawn approval falls back safely to the existing route controls. The adapter contains visually descriptive copy and no SEO overrides, client relationships, delivered services, dates, results or credits.

The owner’s tall-left / wide-upper-right / two-smaller-lower-right motif is used for suitable four-piece mosaics. Lead artwork appears once in the mosaic, with no repeated hero image. Two- and three-image compositions are deliberate variants. The [asset curation audit](ASSET_CURATION.md) explains source-board overlap and exclusions: crops are not claimed as independent deliverables.

The original research files under `docs/portfolio-case-rebuild/` were copied from the documentation branch without replacing current application code. Their SEO strings remain draft proposals. The existing route still gates custom metadata on factual and credit verification, and the site retains `noindex, nofollow`.

## Interaction and media

Each eligible pilot reuses one existing approved motion loop with its poster, lazy mounting, visibility suspension, source selection and pause control. Static content is fully rendered without JavaScript. A dedicated, scoped presentation script adds nonblocking, one-time heading and figure arrivals; reduced motion, Save Data, focus, early scrolling and animation failure restore the visible composition. Native scrolling and genuine case/work/service/contact links remain available.

Pilot routes disable the recurring overlay locally so their arrival remains nonblocking. Homepage and other routes retain their existing loader behavior. No new dependencies, video exports, image generators, 3D assets or global animation engines are introduced.
