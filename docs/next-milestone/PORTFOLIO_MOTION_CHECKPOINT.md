# Portfolio motion implementation checkpoint

This branch continues from loader/gradient correction commit `40ccb58` and depends on PR #7 and Contact PR #5. It preserves the approved source artwork and adds a reproducible offline 2D motion pipeline, typed project motion records and publication-gated media routes, plus viewport-managed playback on homepage and Work cards.

This is an early preservation checkpoint. The six composition functions and integration are saved, but the twelve final landscape/portrait MP4 exports are **not rendered yet**. The existing eight SOL/Bunzo landscape keyframes are partial design inspection outputs, not final acceptance evidence. Build/browser/export validation and the final gallery remain unfinished.

All source material is flattened PNG artwork. Reveals, masks, decorative construction guides and moving photographic panels do not constitute rigged vector logos or physical 3D packaging. Original pixels, filenames and crop bounds are retained by the generator; final renders will record source hashes and loop seam checks.

No merge, deployment or push to the separate Netlify repository is part of this checkpoint.
