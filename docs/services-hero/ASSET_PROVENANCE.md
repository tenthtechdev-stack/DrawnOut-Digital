# Services milestone — shared emblem and portrait

`BrandEmblem.astro` frames the emblem from the original supplied transparent 1920×1080 PNG, `src/assets/brand/drawnout-logo-provided.png`. The source is recorded in the existing asset audit. It does not reuse an optimized navigation thumbnail. Its SVG viewBox crops the original emblem region without changing its proportions; the image remains raster artwork, not newly drawn vector paths. PNG output preserves the supplied pixels, and the component caps its CSS width at 440px against approximately 460 native emblem pixels.

The two SVG files under `design-assets/brand-originals/` and their README were inspected. Both SVGs wrap the same hand/emblem composite and are not independent vector logos. They are unchanged and are not substituted for the emblem in these heroes.

The About composition retains the owner-approved expressive founder sketch byte-for-byte. A warm paper circle provides contrast for its charcoal strokes against the new dark hero. The original personal photograph and rejected illustration candidates remain private. No founder name is assigned to a position in the artwork.

The existing signature hand/plaque footer remains its previously documented 2D prototype. This milestone does not create a new hand, photographic asset or 3D model.
