## Evidence boundaries

Full-page stills visit the ordinary lazy artwork and return to the real top-of-page position. A separate Chromium software compositor prevents the cloud GPU backend’s known repetition on very tall screenshots. All original screenshots are retained at full resolution. The capture manifest records app source hashes, geometry, image loading, video playback samples, durations and any browser failures.

Some supplied images are crops of a shared original board; the asset audit explains their curation. They are visual perspectives, not separate verified client deliverables. No new project facts, imagery, videos, services, credits or outcomes were invented. Custom SEO proposals remain inactive. The inherited hand/plaque is a layered raster prototype.

Physical iOS Safari/Android testing and owner visual approval of these five pilots remain outstanding. No automatic rollout to the remaining six cases, merge, deployment or Netlify mirror push is part of this review.
