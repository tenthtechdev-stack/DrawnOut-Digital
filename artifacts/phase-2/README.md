# Phase 2 — Afterglow homepage storytelling

Visual review of the approved Afterglow direction extended into a complete static homepage narrative: original DrawnOut copy, integrated capabilities, editorial portfolio imagery, studio philosophy, strategic approach, creative process, ideal-client positioning, and the final enquiry invitation.

These are authorized **local/development-only draft-preview captures**. The real portfolio artwork is unapproved for website publication; project records remain drafts and production builds exclude that artwork and unapproved case routes. Publishing this review gallery does not deploy a public site or authorize client claims.

All 28 PNGs are available at their captured resolution. Click an image or a full-page link to inspect it directly on GitHub.
